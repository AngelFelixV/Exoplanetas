# Análisis Exploratorio de Exoplanetas

Proyecto de EDA (análisis exploratorio de datos) sobre el catálogo de exoplanetas confirmados, usando datos del NASA Exoplanet Archive.

## Cómo reproducir este proyecto

1. Clonar el repositorio
2. Crear el entorno: `conda env create -f environment.yml`
3. Activar el entorno: `conda activate exoplanets-eda`
4. Descargar los datos: `python src/download_data.py`
5. Abrir el notebook: `jupyter notebook notebooks/01_eda.ipynb`
